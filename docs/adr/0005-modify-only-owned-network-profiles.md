# Modify only owned network profiles

The application may create, reconcile, activate, deactivate, or remove only NetworkManager profiles carrying its stable ownership marker; a correct external profile can be observed and reported but never edited or deleted. The managed profile is system-wide so NetworkManager can restore sharing after reboot or device replug without the application running. Disabling sharing deactivates the profile and disables autoconnection without deleting it; deletion is a separate confirmed operation. Package removal never changes the profile or live networking. Repair may replace an external profile as the active downstream configuration only after informing the user, preserving the external profile so that the app cannot silently appropriate or destroy working host-network configuration.
