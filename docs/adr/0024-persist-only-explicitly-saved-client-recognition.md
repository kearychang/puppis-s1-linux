# Persist only explicitly saved client recognition

Up to ten saved clients may persist in a versioned, user-only XDG JSON file containing a user-assigned label, client hardware address, last-observed timestamp, and the address set from the latest observation. This deliberately narrows ADR 0020's prohibition on persistent MAC addresses: persistence occurs only after an explicit save action, creates no automatic observation history or trusted identity, remains clearable per client and as a whole, and never enters logs, traffic initiation, or access control. Raw labels and hardware addresses remain excluded from diagnostics, while redacted saved-client aliases, last-observed times, last observed client addresses, and current-observation state may appear in the user-reviewed preview; this accepts bounded local identifier retention so users can recognize returning client devices without adding privileged lease access or a database.
