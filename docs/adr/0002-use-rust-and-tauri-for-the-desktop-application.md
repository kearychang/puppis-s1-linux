# Use Rust and Tauri for the desktop application

The production application will use a UI-independent Rust core behind narrow Tauri 2 commands, with a client-only Svelte frontend in strict TypeScript responsible only for presentation and transient form state. Compared with a native GTK 4/libadwaita UI, Tauri adds an IPC and web-security seam but lets the project use Ubuntu's WebKitGTK runtime, keeps distribution substantially lighter than bundling a browser engine, and makes UI development more accessible without moving protocol, networking, secrets, validation, or rollback out of Rust. Production uses one local-only webview with no navigation, remote content, generic shell/filesystem/network plugins, or developer tools; commands are explicitly allowlisted to that window and user-selected external documentation opens in the system browser.
