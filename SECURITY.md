# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/kearychang/puppis-s1-linux/security/advisories/new). Do not open a public issue containing exploit details, credentials, SSIDs, MAC addresses, serial numbers, diagnostics, packet captures, or other private device and network data.

Ordinary bugs and feature requests belong in [GitHub Issues](https://github.com/kearychang/puppis-s1-linux/issues).

## Scope

Security fixes target the latest released version and the default branch. This project is an unofficial community tool, has no automatic updater, makes no outbound internet requests, and publishes binaries only through [GitHub Releases](https://github.com/kearychang/puppis-s1-linux/releases). Verify the accompanying SHA-256 checksum before installation.

Live hardware research scripts are unsupported laboratory tools and are not installed with the application.
